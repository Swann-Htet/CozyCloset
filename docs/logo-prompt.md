# Cozy Closet - logo prompts

Game name: **Cozy Closet**  
Tagline: *Draw it. Hang it. Love it.*

Save the finished logo as `assets/logo.png` (transparent PNG, about 1024 px wide). The main menu shows it
automatically. Until then it shows a pixel-style text title.

## Palette

| Color | Hex |
|---|---|
| Peach | `#ff8a6b` |
| Butter yellow | `#ffd36e` |
| Mint | `#5fcf9f` |
| Lilac | `#a98bff` |
| Cream | `#fff3e0` |
| Outline navy | `#261b3d` |

## 1. Full logo (name + emblem)

```text
Pixel art game logo for a cozy clothing shop simulation game called "Cozy Closet".
A cute chunky pixel-art wooden wardrobe with its doors open, showing a hanging rail of colorful hoodies, t-shirts and a jacket on little hangers.
Above it, the words "Cozy Closet" in a bold chunky pixel font, with a 3D bevel, thick dark navy outline (#261b3d) and a soft drop shadow.
Small pixel sparkles, a tiny hanger icon and a needle-and-thread accent.
Warm palette: peach #ff8a6b, butter yellow #ffd36e, mint #5fcf9f, lilac #a98bff, cream #fff3e0.
Cute, soft, relaxing 16-bit style, crisp square pixels with no anti-aliasing and no blur.
Centered, horizontal layout, transparent background, game title screen quality.
```

Avoid / negative prompt:

```text
no realistic photo, no gradients, no blurry edges, no extra text, no watermark, no people's faces, no 3D render, no cluttered background
```

## 2. Icon only (favicon, app icon)

```text
Square app icon, pixel art, a cozy wooden wardrobe with open doors and a colorful hoodie on a hanger inside, thick dark navy outline, warm peach and cream colors, tiny sparkles, centered, transparent background, 16-bit style, crisp pixels
```

## 3. Wordmark only (text, no picture)

```text
"Cozy Closet" game title wordmark in a chunky pixel font, peach and butter yellow letters with a thick navy outline, 3D bevel and a hard drop shadow, a small hanger replacing the dot or a letter detail, transparent background, crisp pixels, 16-bit style
```

## Tips

- Ask for 3:1 or 16:9 and around 1024 px wide, with a transparent background.
- If the pixels come out soft, add: "low-resolution 128px pixel art, upscaled with nearest neighbor".
- Generate 4 options, pick one, and clean up edges in a pixel editor if needed.
